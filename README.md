# J.A.R.V.I.S.

A modular offline AI-inspired command platform with an optional local generative intelligence layer.

## Run

```bash
python main.py
```

## Features
- Futuristic HUD interface inspired by the provided design
- Local command router and knowledge core
- Telemetry logging and analytics
- Mission report generation
- Optional local LLM detection
- Graceful offline fallback mode
